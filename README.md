<h2 align="left">Features :--></h2>

###

<p align="left">1. You can register in the website as three of types like admin, tutor or student. By default the role is student.<br>2. An admin have full control of rights like delete session, edit session, approve or reject sessions, delete materials, edit materials and remove users and many more.<br>3. A tutor can have also many rights like create session, add materials, edit materials, delete materials and many more.<br>4. A student can have some rights like book session and pay for the session. He can create note and do many more things.</p>

<h3 align="left">How Could You Use This Code : --></h3>

###

<p align="left">For Client Side : At first you have to clone or download the code from the GitHub. And then you have to open the code in the Visual Studio Code editor and then you have to run command "npm i" in the terminal and you can use the client side code by updating your env.local file like firebase configuration and "VITE_Payment_Gateway_PK". Now you can use the code.</p>

###

<p align="left">For Server Side : Same as client side and you have to create a .env file and then update this : DB_USER, DB_PASS, ACCESS_TOKEN_SECRET, STRIPE_SECRET_KEY. Now change the DB connection string and you are ready.</p>
